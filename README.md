# ABCD Home - Architecture & Construction Studio

Official web platform for ABCD (Architects, Builders, Consultants & Designers) — an architecture, interior design, and turnkey construction studio based in Cherkala & Kanhangad, Kerala.

## Tech Stack
- **Framework:** React + Vite
- **Styling:** Tailwind CSS + Custom Design Tokens
- **Animations:** Framer Motion
- **Icons:** Lucide React

## Getting Started

### Prerequisites
- Node.js (v18+)
- npm or yarn

### Installation
```bash
npm install
```

### Run Locally
```bash
npm run dev
```

### Build for Production
```bash
npm run build
```
